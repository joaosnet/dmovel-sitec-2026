## 📌 Overview

**DMovel** is an open, distributed, and bilingual assistive technology platform designed to transform urban mobility and physical accessibility in the Amazonian context (Belém, PA) and university campuses.

This repository hosts the official interactive web presentation prepared for **SITEC UFPA 2026 (Semana do Instituto de Tecnologia • September 1 & 2, 2026)**. It has been built with extreme attention to detail, adhering to **AAA software engineering and accessibility standards**.

---

## 🎯 Key Highlights of the Presentation

### 1. 🎬 Fullscreen Motivational Video Intercalation
- Features the **motivational documentary video produced by Prof. Kelly for DMovel** (All rights reserved to DMovel / UFPA).
- Allows the presenter to press <kbd>M</kbd> (or click the video button) to transition smoothly into a fullscreen cinematic view, and return instantly to the exact active slide without losing presentation state.

### 2. 📱 Persistent Live Testing QR Code on Every Slide
- Every single slide includes a high-contrast, scannable QR Code directing attendees and students straight to the live production Web App:
  👉 **`https://lapshub.github.io/dmovel_web_app/`**
- Slide 1 features an Opening Hero Card, Slides 2–5 include a persistent top-right badge, and Slide 6 concludes with a Mega Audience QR Code for live demonstrations and Q&A.

### 3. 🌓 Dynamic Projector Mode & Dark OLED Theming
- **Projector Mode (Light Theme):** Calibrated with ultra-bright `#F8FAFC` backgrounds, deep navy `#0F172A` text, and royal `#0361A3` branding to eliminate glare and ensure crystal-clear visibility across large, illuminated auditoriums.
- **Dark Mode (OLED):** Midnight slate theme (`#070B19`) with high-contrast glowing accents.
- Instant switching via the <kbd>T</kbd> key.

### 4. ♿ Built-in Universal Digital Accessibility (WCAG 2.1 AAA)
- **Text-to-Speech (TTS) Voice Narration:** Press <kbd>V</kbd> to listen to the slide titles, key points, and speaker notes read aloud in natural Portuguese via the Web Speech API.
- **Dynamic Font Scaling:** Adjust typography on the fly with <kbd>+</kbd> and <kbd>-</kbd> (or `A+` / `A-` buttons).
- **Full Screen Reader Support:** Semantic HTML5, `role="region"`, `aria-live="polite"` live announcements, and descriptive `alt` tags for all hardware screen mockups.
- **Accessibility Guide:** Press <kbd>A</kbd> to open the shortcut helper modal.

## 🗂️ 6-Slide Narrative Structure (Product & Engineering Focus)

1. **Slide 1 — Opening & SITEC 2026 Welcome:** DMovel mission, authors, advisors, and opening live testing QR Hero.
2. **Slide 2 — The Urban Challenge in the Amazon & Belém:** Invisible barriers, lack of accessibility data, global & local statistics (15% WHO, 18.6M IBGE).
3. **Slide 3 — The DMovel Solution & Three Core Pillars:** Crowdsourced Cartography, Multi-Criteria Weighted Accessibility Assessment, and Global Inclusion with Neural Translation.
4. **Slide 4 — Mobile Experience & Real Device Validation:** Live execution captures on Samsung Galaxy M34 5G (Android 16): Biometrics/Passkeys, Interactive Vector Maps, Emoji Sliders, and Dark/Light Modes.
5. **Slide 5 — Software Engineering & AAA Tech Stack:** Flutter 3.41, Python 3.14 Free-Threaded (No-GIL) + FastAPI, MongoDB 2dsphere geo-indexing, Redis caching, Dash moderation, and 380+ automated tests without mocks.
6. **Slide 6 — Conclusion, Future Vision & Mega Live Demonstration:** Predictive AI for automated barrier classification via computer vision, accessible campus routing, audience QR scanning, and Q&A.

## ⌨️ Presenter Keyboard Shortcuts

| Shortcut | Function |
| :--- | :--- |
| <kbd>→</kbd> / <kbd>Space</kbd> / <kbd>PageDown</kbd> | Next Slide |
| <kbd>←</kbd> / <kbd>PageUp</kbd> | Previous Slide |
| <kbd>M</kbd> | Toggle Fullscreen Motivational Video |
| <kbd>T</kbd> | Toggle Dark Mode ↔ Projector Mode |
| <kbd>V</kbd> | Start / Stop Text-to-Speech (TTS) Voice Reader |
| <kbd>+</kbd> / <kbd>-</kbd> | Zoom In / Out Typography Font Size |
| <kbd>N</kbd> | Toggle Speaker Notes Drawer |
| <kbd>A</kbd> | Open Universal Accessibility Guide |
| <kbd>F</kbd> | Toggle Fullscreen Browser Mode |
| <kbd>Home</kbd> / <kbd>End</kbd> | Jump to First / Last Slide |
| <kbd>Esc</kbd> | Close Video Player or Active Modals |

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/LAPSHub/dmovel-sitec-2026.git
   cd dmovel-sitec-2026
   ```

2. **Serve with any HTTP server (e.g. Python):**
   ```bash
   python -m http.server 8000
   ```

3. **Open in browser:**
   Navigate to `http://localhost:8000/`
