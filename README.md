## 📌 Overview

**DMovel** is an open, distributed, and bilingual assistive technology platform designed to transform urban mobility and physical accessibility in the Amazonian context (Belém, PA) and university campuses.

This repository hosts the official interactive web presentation prepared for **SITEC UFPA 2026 (Semana do Instituto de Tecnologia • September 1 & 2, 2026)**. It has been built with extreme attention to detail, adhering to **AAA software engineering, multi-device responsiveness and accessibility standards**.

---

## 🎯 Key Highlights of the Presentation

### 1. 📱 Live Embedded Web App Iframe Emulator
- Test the full production Flutter Web App without leaving the presentation tab!
- Press <kbd>I</kbd> or click the **"App Embutido"** button in the bottom bar to open an interactive phone emulator frame with reload, new-tab, and live navigation capabilities.

### 2. 🧭 First-Time Visitor Guided Tour
- New attendees receive an intuitive step-by-step onboarding walkthrough highlighting presentation features, keyboard shortcuts, video playback, and accessibility tools.
- Veterans and returning users can restart the tour anytime via the Accessibility Menu (<kbd>A</kbd>).

### 3. 📱 Multi-Device & Mobile Responsiveness
- Optimized for all screen sizes: **Smartphones (portrait/landscape with touch swipe navigation), Tablets, Desktops, and 4K Auditoriums / Projectors**.
- Touch swipe gestures: Swipe left for next slide, swipe right for previous slide.

### 4. 🎬 Fullscreen Motivational Video Intercalation
- Features the **motivational documentary video produced by Prof. Kelly for DMovel** (All rights reserved to DMovel / UFPA).
- Press <kbd>M</kbd> to transition smoothly into a fullscreen cinematic view, and return instantly to the exact active slide without losing presentation state.

### 5. 📱 Persistent Live Testing QR Code on Every Slide
- Every slide includes a scannable QR Code directing attendees straight to the live production Web App:
  👉 **`https://lapshub.github.io/dmovel_web_app/`**

### 6. 🌓 Dynamic Projector Mode & Dark OLED Theming
- **Projector Mode (Light Theme):** Calibrated with ultra-bright `#F8FAFC` backgrounds, deep navy `#0F172A` text, and royal `#0361A3` branding.
- Instant switching via the <kbd>T</kbd> key.

### 7. ♿ Built-in Universal Digital Accessibility (WCAG 2.1 AAA)
- **Text-to-Speech (TTS) Voice Narration:** Press <kbd>V</kbd> to listen to the slide titles, key points, and speaker notes read aloud in Portuguese.
- **Dynamic Font Scaling:** Adjust typography on the fly with <kbd>+</kbd> and <kbd>-</kbd>.
- **Full Screen Reader Support:** Semantic HTML5, ARIA live announcements, and full keyboard control.

## 🗂️ 6-Slide Narrative Structure

1. **Slide 1 — Opening & SITEC 2026 Welcome:** DMovel mission, authors, advisors, and opening live testing QR Hero & Emulator.
2. **Slide 2 — The Urban Challenge in the Amazon & Belém:** Invisible barriers, lack of accessibility data, global & local statistics (15% WHO, 18.6M IBGE).
3. **Slide 3 — The DMovel Solution & Three Core Pillars:** Crowdsourced Cartography, Multi-Criteria Weighted Assessment, and Neural Translation.
4. **Slide 4 — Mobile Experience & Real Device Validation:** Live execution captures on Samsung Galaxy M34 5G (Android 16): Biometrics/Passkeys, Interactive Maps, Emoji Sliders, and Dark/Light Modes.
5. **Slide 5 — Software Engineering & AAA Tech Stack:** Flutter 3.41, Python 3.14 Free-Threaded (No-GIL) + FastAPI, MongoDB 2dsphere geo-indexing, Redis caching, Dash moderation, and 380+ automated tests without mocks.
6. **Slide 6 — Conclusion, Future Vision & Mega Live Demonstration:** Predictive AI for automated barrier classification, accessible campus routing, audience QR scanning, and Q&A.

## ⌨️ Presenter Keyboard Shortcuts

| Shortcut | Function |
| :--- | :--- |
| <kbd>→</kbd> / <kbd>Space</kbd> / <kbd>PageDown</kbd> | Next Slide |
| <kbd>←</kbd> / <kbd>PageUp</kbd> | Previous Slide |
| <kbd>I</kbd> / <kbd>W</kbd> | **Toggle Embedded Web App Emulator (Iframe)** |
| <kbd>M</kbd> | **Toggle Fullscreen Motivational Video** |
| <kbd>T</kbd> | Toggle Dark Mode ↔ Projector Mode |
| <kbd>V</kbd> | Start / Stop Text-to-Speech (TTS) Voice Reader |
| <kbd>+</kbd> / <kbd>-</kbd> | Zoom In / Out Typography Font Size |
| <kbd>N</kbd> | Toggle Speaker Notes Drawer |
| <kbd>A</kbd> | Open Universal Accessibility Guide & Tour |
| <kbd>F</kbd> | Toggle Fullscreen Browser Mode |
| <kbd>Home</kbd> / <kbd>End</kbd> | Jump to First / Last Slide |
| <kbd>Esc</kbd> | Close Video Player, Emulator or Active Modals |

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/joaosnet/dmovel-sitec-2026.git
   cd dmovel-sitec-2026
   ```

2. **Serve with any HTTP server (e.g. Python):**
   ```bash
   python -m http.server 8000
   ```

3. **Open in browser:**
   Navigate to `http://localhost:8000/`
